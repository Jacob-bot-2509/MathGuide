# MathGuide 前端

大模型高等数学学习辅助与科学研究应用 —— 前端工程。
黑色科幻主题,MG 标志以"故障乱码"风格开场。

## 运行

```bash
npm install
npm run dev       # 开发服务器 http://localhost:5173
npm run build     # 类型检查 + 构建
npm run preview   # 预览构建产物
```

开场动画同一会话内只播放一次,URL 加 `?replay=1` 可强制重播;
动画结束需点击 CONTINUE 进入首页(不自动跳转)。

## 技术栈

Vue 3 + Vite + TypeScript + vue-router + GSAP + KaTeX + MathJax(SVG 输出) + pdfjs-dist(PDF 文本提取)

## 目录

```

  │ http.ts     #   fetch 封装 + OpenAI 兼容 SSE 流解析
  services/     # 业务服务:页面唯一依赖(全部走真实后端)
  │ chatService.ts / authService.ts / accountService.ts / docgenService.ts

  │ speechTips.ts # 语音念法速查贴士数据(中英双语)
  │ todoTime.ts  # 待办日期/重复/状态纯规则
```

生产部署(HTTPS/HSTS/CSP/邀请码注册)见 [`../deploy/README.md`](../deploy/README.md);

## 后端对接(已完成的最小集成)

本地后端骨架位于 `../backend`(starlette + uvicorn + 本地 JSON 存储),契约见
`backend/README.md`。运行方式:

```bash
# 终端 1:后端(8000,默认只绑本机)
cd ../backend && ../.venv/Scripts/python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000
# 终端 2:前端(5173)
npm run dev
```

Windows 下也可直接双击仓库根目录的 `dev.bat` 一键拉起两个服务
(后端由 `dev_reload.py` 监听 `backend/*.py` 自动重启;前端为 Vite 热更新)。

测试:

```bash
npm test        # 语音数学编译器 + SSE 收尾契约 + MathText 渲染/链接安全
npm run build   # vue-tsc 类型检查 + 生产构建
```

- 开发期由 vite 代理把 `/api` 转发到 `http://127.0.0.1:8000`(见 `vite.config.ts`);
- 登录与聊天全部走真实后端(LLM 平台密钥在 `backend/.env.local` 配置,见 `backend/.env.local.example`);
- 登录令牌存于登录态(内存 + localStorage 刷新保持),令牌失效(401)时自动回登录页;
- **退出登录会清除本机会话、归纳本、回收站与语音缓存**(统一入口
  `stores/localData.ts`),避免共用设备换账号时看到上一位用户的数据;
  登录时还会按后端返回的 `accountKey` 校验归属:换账号自动清理,同账号重登
  (包括 token 过期 401 后)保留;设置 → 隐私与安全 也可手动清理;
- `src/api/http.ts` 解析 OpenAI 兼容 SSE,**每帧 payload 为 JSON 字符串**(兼容纯文本),
  正文中的 `\n` 由后端转义,流式拼接无丢字;
- 聊天请求携带最近几轮历史(多轮上下文),会话上下文栈由前端会话系统维护;
- 流式正文按稳定段落分块渲染(不切代码围栏/块级公式),已完成块不重复解析,
  长回答的流式渲染更轻;会话持久化 120ms 合并写,离开页面/附件发送/关闭页签立即 flush。

## 功能说明

- **开场动画**:MG 故障闪现(RGB 分裂 + 乱码解码)→ 环绕公式逐笔描边书写。
  公式用 MathJax SVG 输出(字形是 path,可逐笔动画);
  聊天正文公式用 KaTeX(渲染快,适合流式输出)。
- **学习辅助**:一体化智能答疑对话。智能答疑是对话本身,其余五个模块
  (概念动画演示 / 章节知识导航 / 问题记录 / 公式查询手册 / 待办清单)是指令栏指令,点击即执行
  (指令栏位于输入框下方)。
- **停止后续写**:点「停止生成」截断回答后,气泡右下角出现「回复」按钮;
  点击后把原问题 + 已生成正文交给后端续写,增量追加到同一条消息,不重复已写内容。
- **生成文档**:指令「生成文档」打开三选一弹窗(当前对话问答 / 问题归纳 / 独立要求);
  前两条直接按原问答排版 PDF/Markdown/Word,独立要求先生成可编辑大纲再逐节生成;
  无知识库依据的章节跳过并在 gaps 中列出。
- **待办清单**:指令「待办清单」打开面板,支持一次性 / 每天 / 周期性(周一至周日多选),
  日期精确到年月日、时间到时分;新建时可直接「保存到日程」或「保存到草稿」,
  草稿点「设置好了」转日程。
  当天最早任务到点弹一次高亮提醒面板(无关闭按钮,只能点「好的,我开始做」),
  页面隐藏时发浏览器系统通知;未到点任务显示「在表」,到点显示「进行中」,
  点击「进行中」变「已完成」;跨天未完成变「已过期」并弹「我已知晓」面板。
  支持暂停/恢复、退回草稿、删除;数据按 accountKey 分桶,同账号退出重登保留。
- **章节知识导航(交互化)**:上传/拖入/粘贴教材(txt/md/PDF)→ 点指令一键划分
  章节列表(胶囊按钮)→ 点章节出该章知识指引 → 末尾右对齐黄色「返回」框跳回列表;
  已讲解章节直接跳转不重复生成。
- **问题记录(归纳本)**:数学题解答完成后末尾弹出「是 / 否」按钮,点「是」把题目
  与解答(含参考思路)收纳成档(不分类);点「问题记录」指令展示归纳本,
  点击题目跳回原问答温故知新。一次性提问若干题 → 统一收纳在一个档。
- **搜索范围(数据源勾选)**:指令「搜索范围」开面板勾选研究型提问要检索的平台
  (本地知识库 / arXiv / zbMATH Open / Semantic Scholar / OpenAlex / StackExchange),
  默认全选 = 全平台;取消的平台本轮一个请求都不发(省时也省对方配额),
  选择持久化到 localStorage;范围缩小后指令按钮常驻角标提醒当前非全平台。
- **文件导入三通道**:本地选择 / 桌面拖拽(电脑端)/ 剪贴板粘贴导入(移动端);
  文本与 PDF 自动提取正文交 LLM 阅读理解,扫描版 PDF 友好提示。
- **语音输入 + 念法速查**:点一下麦克风开始、再点一下完成(期间其他操作不打断);
  语音中麦克风旁弹出📓本子图标,点开查看数学符号标准念法(中英双语切换)。
- **问题归纳系统 + 多会话(上下文栈)**:
  - 每个用户问题自动分类到高等数学大板块(数学分析 / 高等代数 / 数论 /
    空间解析几何 / 拓扑学 / 微分方程 / 概率论与数理统计 / 复变函数),
    分类器见 `utils/classifier.ts`(关键词预判,后端路由做最终裁决)。
  - 同板块问题延续当前会话;检测到不同类型的问题时,检索同板块
    旧会话并切回(上下文栈),否则新开会话 —— 避免不同类型问题相互纠缠。
  - 会话持久化到 localStorage(记忆功能,刷新不丢失);
    问题归纳面板按板块显示问题数量,点击问题跳回当时所在的对话。
  - 如需重置历史:浏览器控制台执行 `localStorage.removeItem('mg-learn-sessions')`。
- **LLM 流式回复**:后端转发模型增量(SSE),前端增量节流上屏;流式期间
  贴底自动跟随、上拉阅读不抢滚;生成中发送键变「停止生成」(保留已生成内容);
  研究型问题回答末尾附小字引用区(可点击跳转);数学题解答末尾附🔍复核结论与
  「是 / 否」收录按钮(交互契约 `cmd://…`,MathText 渲染,点击冒泡统一处理)。
- **多轮对话**:请求携带最近 16 轮历史,更早对话由后端滚动摘要压缩,长对话不丢上下文。
- **关于 MG / 服务协议与隐私**:关于页展示当前版本与稳定版、版本记录、MG 用途、
  服务协议/隐私政策入口与开源许可;反馈页将内容预填到 GitHub issue,不经过额外后端。
  隐私政策写明 localStorage、backend/data 与第三方模型/检索平台的数据流向。
- **数据导出与注销**:设置 → 账号管理 可导出账号/用量元数据与浏览器学习数据(JSON);
  注销需当前密码(验证码/第三方账号输入确认词),后端级联删除账号、令牌与用量记录,
  前端清理本机会话、归纳、回收站、语音缓存与待办。
