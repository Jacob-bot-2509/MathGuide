# MathGuide

面向高等数学学习与研究的 AI 助手:知识问答(RAG)、证明解答(双模型复核)、
深度研究搜索(五学术源 + 引用溯源)、语音数学转写、学习成果导出 PDF。

## 快速启动

```bat
dev.bat
```

双击启动后端(8000,自带热重载守护)与前端(5173)。
密钥配置在 `backend/.env.local`(不入库,参考 `backend/.env.local.example`)。
