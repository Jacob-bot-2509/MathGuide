# MathGuide 评测报告

- 评测日期：2026-10-28
- 评测对象：MathGuide 学习问答链路（RAG 检索 + 大模型生成 + 异源评审）
- 数据集：
  - `backend/evaluation/data/course-50.jsonl`（50 题，hash `96cc234331ae39a5`）
  - `backend/evaluation/data/hallucination-50.jsonl`（50 题，hash `a5f67b97fe963011`）
- 模型配置：生成 `aliyun:qwen3.8-flash`，深答 `aliyun:qwen3.8-max`，评审 `zhipu:glm-5.2`
- 原始输出：`backend/reports/eval_course50_v2/`、`backend/reports/eval_hallucination50_v2/`

## 一、数据集说明

`course-50` 覆盖高等数学上册主要章节，共 50 题：极限 7、导数 8、泰勒展开 5、积分 9、级数 4、微分方程 6、线性代数 3、概率统计 4、微分中值定理 2、反例辨析 2。其中 48 题有参考答案，2 题为不可答反例。

`hallucination-50` 为抗幻觉专项集，全部为不可答题，按 domain 分为：反例辨析 29 题、条件矛盾 16 题、超出范围 5 题。

两套题均由项目组按教材章节与现有知识库文档编写，**不是教材原题或公开题库**，参考答案与 `gold_chunk_ids` 需经数学专业人员审核后才能作为正式基准。

## 二、指标定义

- **正确率**：可答题中，最终结论与参考答案一致的比例；数值题允许近似值 1% 容差，表达式题优先用 SymPy 判等，无法机器判定时交评审模型。
- **答案级幻觉率**：答案中至少含一条“无依据断言”的比例。无依据指该断言无法由参考答案、检索资料或题面直接支持；该指标衡量“内容是否有据”，不等同于“答案是否错误”。
- **断言级幻觉率**：无依据断言数 / 总断言数。
- **不可答编造率**：不可答题中，未恰当处理（既未拒答，也未正确指出对象不存在或条件矛盾）的比例。

补充说明：

- c50-046（标准正态分布区间概率）回答为 0.6826，参考答案为“约 0.6827”；已加入近似值容差，判定正确。
- 初版运行有 2 条评审失败（输出截断、超时），已增加评审重试与 2000 token 上限，并对这 2 条补判；本报告为补判后的结果。
- 答案级幻觉率偏高，主要因为评审规则把“参考答案和检索资料未写、但数学上正确的补充内容”也记为无依据。该指标适合衡量答案的“资料支撑度”，不能直接解读为 58.3% 的答案存在事实错误。

## 五、结论与限制

1. 正确率与不可答处理达到可用水平；检索 hit@3 仅 0.667，是当前最明确的短板，建议补充知识库关键词与切片，或扩大 `gold_chunk_ids`。
2. 幻觉指标依赖评审模型 glm-5.2 的单次判断，尚未做人工盲标与一致性（kappa）校准，不能替代人工评审。
3. 两套 50 题均为项目组自编草稿，题面、参考答案和知识点映射需要数学系教师或助教审核。
4. 评测只覆盖学习问答链路，不包含研究深度搜索、语音转写、PDF 导出等功能。
