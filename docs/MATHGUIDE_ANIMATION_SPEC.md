# 各学科视觉隐喻与 Manim 实现指南

## 1. 数学分析（微积分）

- 极限（ε-δ定义）：用动态缩小包围盒，展示"无限逼近"。
- 导数（瞬时变化率）：用割线动态逼近切线。
- 定积分/反常积分：用矩形微元从左向右扫过，用垂直虚线向右无限推进展示面积收敛。
- 无穷级数：用柱状图高度衰减和折线逼近收敛线，展示部分和累积。
- 傅立叶级数：用红、绿、蓝等多色正弦波动态叠加，逼近目标波形。

## 2. 概率论与数理统计

- 条件概率/贝叶斯：用二维面积图或韦恩图，动态收缩样本空间或重新分配信念面积。
- 几何概型：用蒙特卡洛随机撒点（NumPy向量化生成）展示频率逼近概率。
- 大数定律/中心极限定理：用 ValueTracker 控制样本量，动态展示折线平稳收敛或直方图逐渐演变成钟形曲线。
- 公理化定义/可列可加性（抽象概念）：视觉隐喻！用面积为1的正方形代表全集，用无限分割的拼图（1/2, 1/4, 1/8 ...）展示几何级数收敛于整体。

## 3. 高等代数（线性代数）

- 矩阵/线性变换：用 NumberPlane + ApplyMatrix 展示整个网格的拉伸、剪切形变。
- 行列式：用单位正方形/立方体变换后的面积/体积缩放来展示。
- 特征向量：空间剧烈变形时，高亮方向不变、仅长度缩放的向量。
- 线性方程组（三维）：用 ThreeDScene 展示多个平面的相交关系（交于点、线或无交点）。
- 二次型/λ-矩阵/辛空间等高度抽象概念：放弃三维坐标系，采用"等值线投影"、"坐标旋转标准化"、"面积守恒隐喻"等二维动态高亮来表现。
