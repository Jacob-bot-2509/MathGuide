# 隐式曲面网格误差指标

日期：2026-11-29

目的：在决定是否投入自适应网格前，量化均匀 marching tetra 的「三角形数 / 二进制体积 / 最大弦高 / 法向偏差」。

工具：`backend/tools/diagram_mesh_metrics.py`
数据：`docs/reports/diagram-mesh-metrics.json`

指标口径：

- **最大弦高**：每个三角形重心处 `|F|/|∇F|`，近似到零水平面的距离。
- **法向偏差**：三角形法向与重心处 `∇F` 的夹角（取绝对值，忽略朝向）。
- **二进制体积**：Float32 positions + Uint16/Uint32 indices + base64。

## 结论

1. 球面/抛物面：44 分辨率弦高已到 1e-3 量级，继续加密收益递减；64 足够。
2. 圆环/双球：64 分辨率最大弦高仍约 6e-3–9e-3，是球面的 8–12 倍；细特征确实需要更高局部精度。
3. 体积随分辨率约 O(n²)；64 分辨率圆环约 1.24 MB，双球约 1.39 MB；再往上会快速吃满 4 MB 预算。
4. 法向偏差在高分辨率出现非单调尖峰，说明均匀网格在局部退化三角形/薄特征附近不稳定；自适应或双轮廓会改善。
5. 自适应网格的收益主要在圆环、双球、窄缝与高倍放大；普通教材曲面收益有限。当前先发布；自适应/双轮廓等后续再评估。
