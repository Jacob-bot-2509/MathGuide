# 图解不变量

日期：2026-11-02
关联：[防崩溃机制](DIAGRAM_RESILIENCE.md) · [表示形式契约](REPRESENTATION_CONTRACT.md)

目标：不再逐题修图，而是把已出现的问题归纳成类，统一在渲染前/校验时处理。

## 1. 隐藏 token 泄漏

**类**：模型输出截断、大小写错误、类型名拼错，导致 `D]]` / `DJJ` 之类碎片进入正文。

**防线**：
- `MarkerStream._malformed_tail` 剥掉大小写类型名、`type=`、残余 `]`；
- 完整但非法的标记整段隐藏；
- 标记后真正的正文保留；
- 测试覆盖大写、截断、闭合三种形态。

## 2. 形式与内容错配

**类**：概念关系被画成带坐标轴的几何图；抽象题硬实体化；关系题出多张图。

**防线**：
- 显式用户要求优先；
- 概念辨析默认 `tree`，最多 1 张；
- 有步骤才 `flow`；
- 真正关系网才 `relation`；
- 只有用户明确要类比/实体化，且能给出准确图像时才允许 2D/3D；
- 用户明确说“先不要画图/不用配图”时，后端关闭标记与漏标兜底，前端关闭回答结束后的自动补图；直到用户说“可以画图/用三维图”才恢复；
- 节点型图统一清除 shapes/annotations，禁止坐标轴装饰。

## 3. 规范几何被模型手估

**类**：轴斜、切线穿曲线、导函数叠线、梯度方向错、切平面法向量错。

**防线**：
- 2D x/y 轴统一水平/垂直，长度由数据范围决定；
- 导函数曲线不与原函数叠在同一坐标系；
- 切线斜率由曲线表达式/采样点数值计算；
- 切线可被识别为 segment/line 或“直线型 curve”；
- 曲线采样 400 点，切线缩短到跨度的 4%，降低放大后的折线误差；
- 曲面梯度与切平面法向量由表达式数值求导重算；
- 3D 坐标统一 `(x,y,z) → (x,z,-y)`，保持右手系。

## 4. 重复/错误基础设施

**类**：模型自带 x/y/z 线段和标注，与渲染器自动坐标轴重复；原点出现圆盘。

**防线**：
- 3D 过滤穿过原点、无标签或只标 x/y/z 的轴向线段；
- 过滤纯 x/y/z annotation；
- 3D `circle` 画细线圆环，不再画实心圆盘；
- 图解标签与 annotation 文本归一化后去重；
- 曲线没有标签时自动生成 `y=...`，曲面自动生成 `z=...`。

## 5. 排版与视觉层级

**类**：点/箭头过大、标签灰底、节点爆格、边标签重叠、函数式离图太远、标注压住图形、标注互叠、3D 横向留白。

**防线**：
- 2D 标注先量文字宽度并换行，再在锚点上/下/左/右及四角试位；
- 标注以“对象旁”优先：不再把整个主体包围盒当成必须绕开的外框，只避开曲线/线段等实际几何；
- 实心多边形额外登记内部包围框，标签沿多边形边缘就近摆放，不落进填充区域；
- 每条标注、形状标签、边标签都登记占位框，后续标签不得压住已占位标签；
- 节点图边标签沿边错位摆放，避开节点方框、其他边和已放标签；
- 3D 标签按屏幕投影尺寸参与碰撞，只在对象附近的小范围避让，不因整幅包围盒被推到画面边缘；
- 3D 点、箭头、标签按场景尺度缩放；点是注记不是主体；
- 3D/2D 标签不加底板，文字贴近对象；
- 节点宽度按中英文字符实测宽度计算，两行截断；
- 分支流程按层并排，边标签按目标节点分列；
- 曲线标签贴在曲线 62% 位置；
- 2D 点缩小，注释只做轻微避让；
- 3D 画幅固定竖向，相机按对象包围盒中心取景，标签精灵不计入取景。

## 6. 不可渲染 / 生命周期

**类**：只有坐标轴没有图、旧缓存 expr 无采样点、3D 滚出视口消失、坏数据拖垮会话。

**防线**：
- 类型-结构-可渲染性三重校验；无实际几何的图解直接丢弃；
- 3D 平面/圆必须显式给出中心坐标；缺 z 的平面不再默默落到原点；
- `surface3d` 必须有曲面主体；模型漏掉曲面后只剩平面/点时整图丢弃；
- 题面明确写了 `z=f(x,y)` 与水平平面 `z=c` 时，规划阶段只按题面补回缺失的曲面/高度，不猜其他位置；
- 恢复会话重新跑 `parseDiagramSpec`；
- 3D 首次进入视口后保持挂载；
- 单图错误边界、WebGL 丢失提示、配额失败保留旧存档。

## 7. 图解放大视图

**类**：聊天内图解太小，放大后丢失图内交互，3D/GeoGebra 被复制成多实例。

**防线**：
- 桌面双击图解进入左右分屏，分隔条可拖拽；移动端双击弹出浮层；
- 放大区外点击、关闭按钮、Esc、全屏下滑关闭；图内交互不关闭；
- 用 Teleport 搬运同一个 `DiagramBlock`，不复制 3D/GeoGebra 实例，保留 viewBox/相机/内核状态；
- 聊天内图解和焦点舞台统一 `#05070a`，浅色主题下用局部深色 token 保证对比度；
- 移动端图内双指缩图，标题栏/边缘双指缩窗口；窗口达到阈值自动全屏；
- 科研检索分栏与图解放大互斥，退出放大后恢复检索分栏。

## 8. 测试策略

每个类至少一个回归测试，而不是只测某一道题：

- 隐藏 token：大小写/截断/闭合；
- 结构：节点图清装饰、空图拒绝；
- 数学：轴正交、切线关键点/直线型 curve/公式标签去重；
- 3D：轴线段/annotation 去重、右手系映射；
- 排版：分支流程同层、节点宽度、边标签位置；
- 崩溃：超时、熔断、预算、脏数据、配额。

代码入口：`backend/research_diagrams.py` 的 `prepare_diagram` 管线，前端 `DiagramSvg` / `Diagram3D` / `diagramLayout`。
