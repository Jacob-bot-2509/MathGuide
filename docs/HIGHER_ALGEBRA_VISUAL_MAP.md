# 高等代数“可几何表示”版块总表

日期：2026-11-03
范围：只收录能用二维/三维几何、低维投影、水平集、向量场或结构示意图表达的内容。
不收录纯符号代数、纯矩阵证明、纯存在性定理。

说明：

- **GeoGebra** 只负责可嵌入实二维/三维的精确几何构造。
- **语义层** 负责对象定义、选型、基/维数/形式、投影规则、不变量校验和降级。
- 抽象内容不硬画 3D；能画矩阵图、箭头图、水平集、投影图才收录。

## 优先级

- **P0**：实二维/三维可直接画，GeoGebra 深度参与。
- **P1**：需要复结构、四维投影、二次型/辛结构，GeoGebra 只参与局部。
- **P2**：低维外代数、对偶、商空间等“几何化边缘”内容，主要靠我们的结构图。

## 不收录

以下内容主要是符号/结构证明，不能稳定几何化，不进入本表：

- 多项式整除、因式分解、结式、判别式。
- λ-矩阵、Smith 标准形、初等因子。
- 若尔当标准形、有理标准形的完整证明；只保留“不变子空间/链式结构示意图”。
- PID 上有限生成模、结构定理。
- 域扩张、Galois 理论。
- 高维张量、外代数的抽象运算。
- 纯矩阵秩不等式、分块矩阵证明、存在性定理。
- 有限域上的线性代数（无实几何直观）。
- 抽象范畴、同调代数。

## 与 GeoGebra 的分工

- GeoGebra：实二维/三维点、线、面、球、圆锥曲线、二次曲面、交点/交线、实矩阵变换。
- 我们的语义层：底域、形式、基、维数、投影、不变量、视觉选型、校验、降级。
- 我们的渲染层：SVG/Three.js 负责矩阵图、基箭头、平面片、二次曲面、投影说明和抽象示意图。
- 不能几何化的内容：矩阵/箭头/结构图，不硬画 3D。
