# 图解形式权重网

日期：2026-11-02
代码：`backend/diagram_taxonomy.py`
关联：[表示形式契约](REPRESENTATION_CONTRACT.md)

## 1. 目标

用户通常不会说“用 2D 还是 3D”，只会说“帮我把图做出来”。系统必须自己判断：

- 一元函数及其导数 → 2D 曲线；
- 多元函数、偏导数、曲面、梯度 → 3D 曲面；
- 矩阵变换、特征值、行列式 → 2D 几何；
- 三重积分、空间向量、立体 → 3D 几何；
- 算法、证明、推导 → 流程图；
- 概念关系 → 关系图；
- 层级分类 → 树。

判断不是默认值，而是**知识点词表 + 维度证据 + 意图证据**的加权结果。

## 2. 三层权重

1. **类型分**：`VISUAL_CUES` 把知识点映射到 `plot2d / geometry2d / surface3d / geometry3d / flow / relation / tree`。
2. **维度分**：`DIMENSION_CUES` 单独判断 2D/3D，给同族类型加权，不凭空造类型。
3. **意图分**：`INTENT_CUES` 区分“理解/对比/推导/画图”等问法。

段落级再叠加：

- 步骤保持从头到尾的顺序，**不按分数排序**；
- 相邻步骤先用语义承接度判断：`把它/上式/代入/整理/由此` 等承接词、共享关键对象、同类型延续 → 合并到上一步；引入全新视觉对象的关键步骤才单独成图；
- 步骤过细时优先合并承接度最高的一对，软上限 5 步，避免图片密度稀释注意力；
- 非步骤段落按重要度排序，只取显著高于其他段落的点，不凑数；
- 全文主题词辐射 → 相关段落加分；
- 长度降权（但强视觉词和步骤不降权）；
- 寒暄/短句降权。

**步骤粒度由模型负责**：回答提示词要求把连续代入/整理合并，每步是一个完整关键动作，通常 2–5 步；图解只落在关键步骤，不机械地一步一图。

## 3. 覆盖范围

词表按知识域铺开，新增知识点只加词条，不改选型逻辑：

| 知识域 | 典型知识点 | 首选形式 |
| --- | --- | --- |
| 一元微积分 | 函数图像、导数、单调/极值/凹凸、泰勒展开 | `plot2d` |
| 一元积分 | 定积分、面积、弧长、旋转体 | `plot2d` / `geometry3d` |
| 数列与级数 | 收敛/发散、幂级数、傅里叶 | `plot2d` |
| 多元微积分 | 多元/二元函数、偏导、全微分 | `surface3d` |
| 梯度与曲面 | 梯度、方向导数、切平面、法向量、等高线 | `surface3d` |
| 重积分 | 二重积分、曲顶柱体 | `surface3d` |
| 空间几何 | 三重积分、空间向量、球/锥/柱、旋转体 | `geometry3d` |
| 线性代数 | 矩阵变换、特征值/特征向量、行列式、SVD、投影 | `geometry2d` |
| 复变 | 复平面、共形映射、留数 | `geometry2d` |
| 概率统计 | 密度函数、正态/二项分布、回归、联合分布 | `plot2d` / `surface3d` |
| 微分方程 | 斜率场、方向场、相图/相轨迹 | `plot2d` |
| 优化 | 可行域、约束、条件极值、梯度下降 | `geometry2d` / `flow` |
| 离散/结构 | 分类、层级、关系网 | `tree` / `relation` |

## 4. 加新知识点的步骤

1. 在 `diagram_taxonomy.py` 对应的 `VISUAL_CUES` 里加词条和权重（1–3）。
2. 如果它影响维度判断，在 `DIMENSION_CUES` 里补 2D/3D 证据。
3. 在 `backend/tests/test_research_diagrams.py` 的 `test_taxonomy_covers_common_knowledge_points` 加一行期望。
4. 运行后端测试；不需要改评分函数或提示词。

## 5. 可见性

权重计算是**后台决策动作**，不进入用户可见层：

- 不写进 SSE `diagram` 事件；
- 不写进 `ChatMsg.diagrams` / localStorage；
- 不写进图题、节点标签、标注或回答正文；
- 前端只拿到结构化图解数据，不知道分数和选型依据；
- 回答里只讲“看这张图”，不解释“为什么选 3D/权重多少”。

## 6. 边界

- 权重只给建议，用户显式要求仍然优先；
- 规划器可结合上下文改选，避免“关键词命中就画”；
- 类型与结构必须自洽，错类型宁可不画；
- 张数由步骤/段落权重决定，安全上限定在 6，不作为教学节奏依据。
